6.注單相關規則
6-1.注單資料保留90天提供查詢

6-3.遊戲代碼需與gamecode一致

6-4.遊戲中的注單編號需與api回覆我方的注單單號bet_id一致

6-5.電子類遊戲注單若該回合有觸發免費遊戲，則免費遊戲注單需與該局注單整合為一張注單 (待免費遊戲完成後再   產生一張已結算狀態的注單即可)
6-6.注單派彩pay_off_amount欄位請回覆玩家贏錢金額，若未贏錢則為0
6-7.真人類遊戲如果一局內有多筆不同投注的話，需要分開為不同注單不同的注單單號bet_id
6-8.真人類遊戲gamecode為桌別

7.更新注單相關規則
7-1.產生一筆新注單，新注單的注單編號需和原本注單編號相同

7-2.status欄位紀錄為2:改單

7-3.bet_time欄位 (投注時間) 不可更動

6-8.真人類遊戲注單因人為疏失或其他情況導致該局無效時，請立即告知我方並做以下處理：

  • 歸還下注金額給玩家
  • 新增一筆注單需注意的欄位如下：

- bet_amount總投注金額需為原始投注金額

- bet_valid_amount有效投注金額需為0

- pay_off_amount派彩金額需為0

- status注單狀態需為3:撤單
