Sign

每次呼叫都必須驗證網址的sign參數，而sign參數是以傳遞資料及secretkey產生:

先將參數陣列照key值進行升序排序

=> 組成query string

=> 後面串上secretkey後md5加密

<?php

//$data:傳遞的參數陣列，若沒傳遞參數則放空陣列

//$secretKey:代理商的密鑰

function generateSign($data, $secretKey)

{

    ksort($data);

    return md5(http_build_query($data) . $secretKey);

}

將所有請求資料MD5後放在header，用來驗證資料

curl --location 'https://{Domain}/api/v1/{Platform}/createUser?hash=1b6f5306ba2a0ae870f5a41c13db32343f0dfe0202687a46ed86e885a839b8d9'

--header 'Content-Type: application/json'

--data '{"test":"hello world"}'

接口方提供兩個參數供加密驗證使用：appKey 和 appSecret。每次請求接口時，只有兩個POST參數：ak 和 p。


ak參數：ak = appKey值

p參數：p = 加密的請求參數


p參數加密規則


組合請求參數：


  • 將所有請求參數組合成一個字符串格式，其中包含appKey和所有需要傳遞的參數。
  • 示例格式：appKey=appKey值&參數1=值&參數2=值&……&verifyStr=


生成verifyStr：verifyStr 是一個用於驗證數據完整性的MD5 hash。


生成規則如下：


  • 排序：將所有參數（包括appKey和appSecret）按參數名的字母順序（a-z）排序。
  • 拼接：將排序後的參數按參數名=參數值格式拼接，用&連接不同的參數。
  • 剔除空值：如果參數值為空，則該參數不參與MD5加密。
  • 加入appSecret：將所有參數拼接後的字符串末尾加上appSecret。
  • MD5加密：對拼接後的字符串進行32位MD5加密，並轉換為小寫。
