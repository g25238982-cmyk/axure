查詢注單(時間查詢)

GET

參數

類型

是否必填

說明

start_time

string

必填

搜尋起始時間(GMT+8)

yyyy-MM-ddTHH:mm:ss

end_time

string

必填

搜尋結束時間(GMT+8)

yyyy-MM-ddTHH:mm:ss

page

numbe

必填

查詢頁數 (從1開始)

page_size

numbe

必填

每頁顯示筆數 (最小2000, 最大5000)

time_type

int

選填

1=依投注時間查詢，2=依派彩(結算)時間查詢

Request

1. 同時間需可接受多個請求

2. 需回傳所有狀態的注單

3. 若不支援time_type則搜尋bet_time投注時間注單 (需包含搜尋起訖時間)

4. 回傳注單需照bet_time投注時間小到大排序

5. 單次搜尋的最大時間區間90天
6.這個 request 請求需要包含一個值為"gzip" 的 "Accept-Encoding" header。 而得到的 response body 會使用gzip演算法壓縮。

7.一般下注進入的免費轉的贏分算在pay_off_amount
道具和活動以及活動獲得的免費轉贏分都算在jp_win，一般JP中彩也歸類在jp_win
