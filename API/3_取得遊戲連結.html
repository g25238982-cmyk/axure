sign錯誤

1. 建議遊戲連結需設定有效時間，超過有效時間該連結即失效無法使用

2. 同一玩家不能用同一遊戲連結開啟多個視窗

3. 同一玩家不能同時進入多個遊戲

4. 上述情形請彈出相關錯誤訊息，並讓玩家點"確定"按鈕後關閉當前視窗

5. 若電子類遊戲中，玩家在該局遊戲中觸發免費遊戲，或下注到一半因離線或其他原因發生未完成遊戲，未避免注單延遲時間過長，系統需自動完成結算

6. 遊戲連結中若包含遊戲代碼等相關資訊，建議隱藏或進行加密

7.betlimit投注限額請與我方討論，建議提供多組限額讓我方選擇

7. 捕魚類、棋牌類遊戲若RTP非純自然機率，則需支援分組機制，分組參數請與我方人員討論制訂。若無法支援分組機制請提出與我方討論
